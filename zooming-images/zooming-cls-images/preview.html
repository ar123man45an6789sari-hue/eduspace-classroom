⚙️ How to Use in Your Django Project

# 1. Copy entire images folder into your static directory
cp -r zooming-cls-images/* zooming-cls/static/images/

# 2. In your Django templates, load static and use like:
{% load static %}

# Logo in base.html sidebar:
<img src="{% static 'images/logo.svg' %}" alt="ZoomingCLS" height="40">

# Empty state in dashboard.html:
<img src="{% static 'images/illustrations/empty-classrooms.svg' %}" width="280">

# Auto avatar by username first letter in profile:
<img src="{% static 'images/avatars/avatar-'|add:user.username.0.upper|add:'.svg' %}" width="40">

# Favicon in base.html <head>:
<link rel="icon" type="image/svg+xml" href="{% static 'images/favicon.svg' %}">
